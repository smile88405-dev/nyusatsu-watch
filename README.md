# みやぎ入札ウォッチ（nyusatsu-watch）

自治体が公開している入札結果を集めてデータベースにし、新しく出たもの・変わったものを知らせるツールです。
大崎市・仙台市・宮城県に対応しており、1つの画面で切り替えて見られます。業者名で自治体をまたいだ入札履歴も引けます。

議員や市民が「あの会社はどこで何を落札しているか」「1者応札はどれくらいあるか」を、PDFを1本ずつ開かずに調べられるようにすることが目的です。

- 閲覧画面: `docs/index.html`（データ埋め込み済みの単一HTML。ダウンロードしてブラウザで開くだけで動きます）
- データ: `data/nyusatsu.sqlite`、`out/*.csv`（Excel用・BOM付きUTF-8）

**デモ版です。機械読み取りなので、公表に使う数字は必ず原本で確認してください。**

## 収録範囲

| 自治体 | 対象 | 取得元 |
|---|---|---|
| 大崎市 | 入札結果PDF（財政課契約担当分）令和6〜8年度、入札公告ページ | 市サイト |
| 仙台市 | 入札情報公開システムの「工事」入札・見積結果 令和8年度 | 入札情報公開システム |
| 宮城県 | 入札情報サービスの「建設工事」入札結果 令和7〜8年度（予定価格400万円超） | 入札情報サービス |

件数と期間は閲覧画面の「しくみ」タブに出ます。

## 使い方

```
python -m nyusatsu_watch run                     # 全自治体: 収集 → 解析 → 差分レポート → 出力
python -m nyusatsu_watch run --src osaki         # 自治体を指定（osaki,sendai,miyagi をカンマ区切り）
python -m nyusatsu_watch run --years 2025,2026   # 年度を指定（既定は今年度）
python -m nyusatsu_watch company 古川土地         # 業者の入札履歴（全自治体）
python -m nyusatsu_watch export                  # DBから out/ と docs/ を作り直す
```

必要なもの: Python 3.9以上（追加のpipパッケージなし）、大崎市のPDF解析に poppler の `pdftotext`。

- Ubuntu: `sudo apt-get install poppler-utils`
- macOS: `brew install poppler`
- Windows: poppler for Windows を入れて `pdftotext.exe` に PATH を通す

実行するたびに `out/diff_日付_runNN.md` に差分レポートが出ます。`watchlist.txt` に業者名を書いておくと、新着や状態変化にその業者が出たときレポートに載ります。

定期実行の例は `examples/github-actions.yml` にあります（GitHub Actions で週2回取得し、`docs/` を更新する構成）。

## 差分の考え方

- **新着**: 前回の記録にない案件・公告・原本PDF
- **状態が変わった案件**: 一覧上の表示（状態・落札者・金額・更新日時）が変わった案件。詳細を取り直して「選定中 → 落札」のように記録します
- **差し替え**: 同じURLで中身（ハッシュ値）が変わったPDF
- **掲載終了**: 一覧から消えた公告

## 構成

```
nyusatsu_watch/
  core.py               共通: DB、差分レポート、CSV・閲覧画面の出力
  http.py               間隔をあけてアクセスするHTTPクライアント
  sources/osaki.py      大崎市（PDFを解析）
  sources/sendai.py     仙台市（検索システムの一覧→詳細）
  sources/miyagi.py     宮城県（同上）
  viewer_template.html  閲覧画面のひな形
watchlist.txt           見張りリスト
data/nyusatsu.sqlite    データベース（documents / tenders / bids / notices / runs）
out/                    CSVと差分レポート
docs/index.html         閲覧画面（GitHub Pages を docs/ に向ければそのまま公開できます）
```

### 自治体を追加するには

`sources/` にモジュールを1つ足し、`NAME` `LABEL` `SCOPE` `PORTAL` と `run(con, run_id, opts)` を用意して、`__main__.py` の `SOURCE_NAMES` に名前を加えます。
`run` の中では案件を辞書にして `core.upsert()` に渡すだけです（`sendai.py` が一番短い見本です）。
仙台市と同じ「入札情報公開システム」、宮城県と同じ「入札情報サービス」を使っている自治体は、URLと機関コードを変えれば動く可能性があります。

## 数字を使うときの注意

- 落札率は「落札額 ÷ 予定価格等」。大崎市・宮城県は予定価格、仙台市は予定価格が画面に出ないため**設計額**に対する比率です。自治体間でそのまま比べられません。
- 宮城県は予定価格が載っていない案件があり、その分は落札率を出していません。
- 金額は各自治体の表示どおり税抜です。
- 大崎市の「予定価格超過」「落札不適当」は調書の文言ではなく、調書の数値と総合評価の評価調書から判定した分類です。
- 業者名は全角半角・空白・「株式会社/(株)」のゆれをそろえて照合しています。同名の別会社を1社と数える可能性、支店名の付き方で分かれる可能性があります。
- 読み取りの検算（調書の業者数と読み取り数の不一致、落札者を特定できない等）に引っかかった案件は「要確認」列に理由が入ります。

## 取得先への配慮

- アクセスは1件ごとに1秒以上あけ、新規・変更分だけを取りに行きます。
- 各サイトの利用条件は利用者自身で確認してください。短い間隔での大量アクセスはしないでください。
- 収録しているのは、各自治体が入札結果として公表している情報（案件名・法人名・金額など）です。
